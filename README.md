# Ойдин · С любовью, навсегда ♡

Личный сайт-поздравление с 22-летием Ойдин, созданный от имени её брата.

## Что внутри

- Вступительный экран: кнопка открывает поздравление и запускает музыку.
- История дружбы с детства, личное письмо, фотоальбом и раздел про Пуму.
- Пять музыкальных фрагментов с автоматической сменой, выбором песни, паузой и громкостью.
- Анимированные детали и галерея фантазийных портретов в любимых вселенных.
- Адаптивная вёрстка и поддержка уменьшенного движения.

## Запуск

Сайт состоит из HTML, CSS и JavaScript; сборка и установка зависимостей не нужны.

Из папки проекта запустите:

```sh
python -m http.server 4173 --directory dist
```

Откройте http://localhost:4173 и нажмите «Открыть поздравление».
Звук запускается по нажатию, чтобы соответствовать ограничениям браузеров.

## Размещение и редактирование

Папка `dist` содержит готовый сайт и все материалы. Её можно разместить на статическом хостинге.

- `dist/index.html` — содержание сайта.
- `dist/music.js` — список музыкальных фрагментов и управление воспроизведением.
- `dist/assets` — фотографии, музыка и фантазийные портреты.
- `dist/welcome.css` — оформление вступительного экрана.
- `dist/effects.*` — анимации и небольшие интерактивные детали.
- `dist/multiverse.*` — галерея любимых вселенных.

Шрифты загружаются из Google Fonts; при отсутствии сети используются системные шрифты.

## Личные материалы

Проект содержит семейные фотографии и музыкальные фрагменты. Повторное использование материалов требует соответствующих прав и согласия изображённых людей.

## Netlify

Подключите этот репозиторий в Netlify. Папка публикации — `dist`; команда сборки не требуется. Эти настройки уже указаны в `netlify.toml`.
